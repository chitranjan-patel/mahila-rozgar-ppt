## 📌 Project Overview

This is an interactive 15-slide web presentation on:
- AI Tools (ChatGPT, Google Gemini, Canva AI)
- Digital Marketing (Facebook, Instagram, WhatsApp Business)
- 5 KM Radius Local Ads
- Women Empowerment & Self-Reliance

## 🚀 How to View

1. Open `web/index.html` directly in your browser, OR
2. Run a local server:
   ```bash
   python -m http.server 8000
   ```
   Then visit: [http://localhost:8000/web/index.html](http://localhost:8000/web/index.html)
